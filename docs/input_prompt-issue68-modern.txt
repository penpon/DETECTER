# 調査依頼: 劣化耐性AI画像検出器の追加学習計画 (DCPT + So-Fake-Set) は2026-09時点でモダンで最適か

## 核心の問い

以下の追加学習計画は、2026年9月時点の公開研究水準で最適な選択か。より新しい・より単純な・より効く手法が既に存在して置き換わっていないかを検証してほしい。特に2026年6月〜9月の最新成果 (arXiv投稿、NTIRE 2026公式結果、ICCV/ECCV併設ワークショップ、GitHub上の活発な実装) を重点的に確認すること。

## 検証対象の計画

- 学習方針: DCPT (Degradation-Consistent Paired Training、同一画像のclean/degradedペアで特徴を揃える学習。Synthbuster 8劣化条件平均でbaseline比BAcc +9.1pt、JPEG条件で+15.7〜17.9pt、推論コスト増なしと報告)。
- 要素借用: NTIRE 2026 3位手法 LPT (基盤モデル + LoRA + 実劣化再現) の要素を小規模に取り入れる。
- 学習データ: So-Fake-Set (約223万枚、32生成器、CC BY 4.0とされる) + 自前生成画像。So-Fakeが行う4拡散加工+スクリーンショット劣化を学習中に再現する。
- 規模: フル学習ではなく小規模パイロット (手法がこの分布で効くかの確認のみ)。
- 評価: 学習に使っていない評価群で群単位 TPR@FPR(1%/0.1%)。公開報告のSo-Fake-R1水準 (OOD約72、1024+JPEG75で約70) と同等以上なら継続。

## 前提: こちらの分布と実測

- 判定対象はSNS掲載画像。長辺1024px縮小+JPEG Q75再圧縮相当の加工を通る。実写・生成の双方が同じ加工を通る。
- コホート: 実写586群 (iPhone撮影 + EXIFなしスクリーンショット・保存画像を含む) + 生成115群 (GPT Image 2系58 + Nano Banana系57)、双方SNS相当加工済み。
- 受動検知の壊滅を確認済み: 誤検知0動作点での生成検出は UFD 0/91群、CuRe 0/91群、Community Forensics 1/91群、EFFORT 2/91群。
- 透かし計測 (OpenAI Content Provenance API実測): GPT Image 2系のSynthIDは加工後も31/31で100%検出。実写で誤検知0。Nano Banana系は未計測。
- 運用目標はFPR ≤ 0.1%維持。accuracy/AUCではなく群単位TPR@FPRが主指標。
- 計算環境は普段CPUのみ。学習は外部GPUを借りる想定。ストレージ制限50GB (NTIRE学習セット114GBは分割利用)。

## 検証してほしい仮説

H1. DCPTは依然として最先端の劣化不変学習か: DCPT以降 (論文公開〜2026-09) に、degradation-consistent/paired training系の上位手法・改良版・反証が出ていないか。GlobalForge (local info bottleneck + global reasoning + contrastive) 等との新しいの優劣関係は。

H2. So-Fake-Setは現時点で最適な学習データか: 公称値 (223万枚、32生成器、CC BY 4.0) の実態確認。より新しい・大規模な・実SNS伝送を含む学習セット (2026年公開のもの) がないか。学習側と評価側 (GPT Image 2 / Nano Banana級) の生成器分離は成立するか。

H3. 自前の追加学習がまだ必要なのか: 2026年後半に公開された検出器 (NTIRE上位再現、新しいfoundation modelベースの検出器、透かし検出APIの拡充) が「GPT Image 2 / Nano Banana × 1024+JPEG75 × FPR≤0.1%」を学習なしで既に解いていないか。解いているなら計画は不要。

H4. LPTの要素借用は正しい選択か: NTIRE 2026の1位・2位手法は何をしたのか。3位LPTを選ぶ理由が成立するか (計算資源・再現性・公開状況)。LoRA + 実劣化再現より効く要素が上位手法にないか。

H5. 低FPR動作点での追加学習の先行例: 追加学習が効いた報告のほとんどはaccuracy/BAcc改善であり、「実写スコア分布の右裾を引っ込める」効果をTPR@FPR≤1%で定量化した研究があるか。実写側の裾 (スクリーンショット等) も同時に上がって相殺される失敗例はあるか。

H6. より単純な代替で同等以上にならないか: test-time augmentation + 較正、公開重みのまま閾値再較正、SynthID等透かしレイヤの強化、selective prediction (不確実域保留) の組み合わせで、追加学習なしに目標へ届く設計がないか。

## 調査論点

1. 2026-06〜2026-09の劣化耐性検出の新着: arXiv・OpenReview・採択済み会議 (ICCV 2025以降、CVPR/NeurIPS/ICLR 2026) で、この計画を古く・不要にする成果の有無。
2. DCPT原論文の厳密な条件と再現性: ベースモデル、データ規模、評価がFPR極小点を含むか、コード/重みの公開状況。
3. NTIRE 2026 (AI-generated image detection系) 公式結果: 上位手法の構成比較、公開コードの有無、必要計算資源。
4. So-Fake-Setの実態: ダウンロード方法、実容量、生成器リスト、real画像の由来、ライセンスの正式表記、商用生成器の含有有無。
5. 学習時劣化再現と実SNS伝送の差: So-Fake式4拡散+スクショ再現はRRDataset型の実伝送とどこまで一致するか。ミスマッチで過大評価を防ぐ評価プロトコル。
6. パイロット規模の設計根拠: 「効く/効かない」を群単位TPR@FPRで判断するのに必要な最小学習枚数・評価群数。生成器leave-one-out評価の標準手順。

## 出力形式

- 冒頭に H1〜H6 の判定表 (成立/一部成立/不成立/証拠不足 + 一言根拠)
- 次に「この計画は2026-09時点でモダンか」の総合判定: 継続 / 一部差し替え (何を何に) / 中止して別手法へ、を理由付きで
- 論点ごとに一次ソースリンク付き要約 (論文・公式コード・公式データセットページ中心)
- 最後に優先度順アクション表: 開始前に確認すべき事項、推奨する最小構成
- 不確かな内容は「推測」と明記
