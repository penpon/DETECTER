# 同じ条件による画像加工

`detecter.derive_jpeg` は元画像を変更せず、JPEG品質変更と縮小を独立した条件として生成します。
実写・全体生成・部分生成編集・不明のラベルによって加工条件を変えません。
切り抜き、スクリーンショット、JPEG品質と縮小の組合せは対象外です。

```sh
uv run python -m detecter.derive_jpeg --ledger data/ledger.jsonl \
  --qualities 95,85,75 --long-sides 1024,512 --output data/derived.jsonl
```

既定値は上記の5条件です。品質は1〜100の整数、長辺は1以上の整数を指定できます。
重複値と条件が両方空の指定は拒否します。片方だけ実行する場合は `--long-sides ''` または
`--qualities ''` を指定します。共通CLIの `detecter derive-jpeg` への接続はIssue #11が担当します。

## 生成するもの

- `data/derived.images/`: ハッシュが一意な派生画像です。
- `data/derived.jsonl`: 派生画像の台帳です。入力と同じ形式で、`ledger validate` に渡せます。
- `data/derived.conditions.jsonl`: 入力画像と加工条件の組合せごとの結果です。同じ画像になる条件も省略しません。

出力先のディレクトリとファイルは新規作成します。既存の入力・出力を上書きしません。
入力台帳を検証してから加工します。画像加工中に失敗した場合は終了コード1を返し、台帳を書き出しません。
途中まで生成した画像は出力ディレクトリに残るため、再実行は別の出力名を指定してください。

## 固定した加工条件

最初にEXIFの向き補正を適用し、RGBへ変換して付随情報を除去します。
JPEG条件は画像サイズを変更せず、品質だけを変えます。色差間引きは無効です。
最適化とプログレッシブ形式は無効にします。

縮小条件は縦横比を保持したLANCZOS補間で、長辺を指定値以下にします。
元画像が指定値以下なら拡大しません。縮小後は可逆圧縮のPNGへ保存します。
PNGの圧縮レベルは6です。JPEG再圧縮による変化を縮小条件へ混ぜません。

派生画像の加工履歴は `history` の末尾へ追記します。加工種別、前処理版、Pillowの版、
向き補正、RGB変換、補間方式、JPEG品質、指定長辺、出力サイズ、保存条件を記録します。
元画像IDとハッシュは `source_image_id` と `source_sha256` に保存します。
ラベル、分割先、元画像グループ、既存加工履歴、出所、利用条件を継承します。

## 同じ画像になる条件の記録

短い画像への1024px条件と512px条件など、加工後のバイト列が同じになる場合があります。
台帳のハッシュ重複を避けるため、同じ元画像グループ内では画像を一度だけ保存します。
異なる元画像グループの加工結果が同じハッシュになった場合は、ラベルや分割先の混入を防ぐため拒否します。

`derived.conditions.jsonl` は各条件について元画像ID・元画像ハッシュ・元画像グループ、
加工条件、参照先の画像ID・画像ハッシュ、次の状態を保存します。

- `created`: 新しい派生画像を保存しました。
- `duplicate`: 同じグループの既存画像と一致し、その画像IDを参照します。
- `unchanged`: 元画像のバイト列と一致し、入力台帳の画像IDを参照します。

派生台帳には `created` の画像だけが含まれます。加工条件別の評価では条件記録も参照してください。
`duplicate` と `unchanged` を未実行として扱わず、参照した画像の測定結果を使います。
条件記録の行を独立標本として数えず、元画像グループ単位で分母を計算します。

## 公開関数と確認

`derive_images(ledger, directory, qualities=(95, 85, 75), long_sides=(1024, 512))`
は派生画像を作り、`(派生台帳の行, 加工条件の結果)` の2つのリストを返します。
`main(argv)` が台帳と条件記録を保存します。

```sh
uv run python -m unittest discover -s tests -p test_derive_jpeg.py -v
```

テストは一時生成した画像だけを使い、EXIF、RGB変換、拡大禁止、ラベル継承、再現性、
ハッシュ重複、異なるグループの衝突、元画像不変、既存出力の上書き拒否を確認します。
