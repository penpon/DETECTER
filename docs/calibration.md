# 調整用データによる判定境界の選択

保存した台帳と計測記録から境界を選び、評価専用の判定設定を保存します。
画像やモデルは読み込みません。最終評価用の画像を含む台帳を渡すと失敗します。
`--split tuning`は入力を絞る指定ではなく、全入力が調整用であることの指定です。

```sh
uv run python -m detecter.calibration --ledger data/tuning-ledger.jsonl \
  --measurements results/tuning-measurements.jsonl --split tuning \
  --output decision-config.json
```

共通CLIへの接続はIssue #11が担当します。接続後は`uv run detecter calibrate`に
同じ引数を渡せます。`--output -`は標準出力です。既存ファイルは上書きしません。
終了コードは候補の作成が0、目標未達が1、入力や保存の失敗が2です。

## 入力検査

- 全台帳行の分割先が`tuning`であることを最初に検査します。
- 台帳と計測の画像ID集合は完全一致が必要です。重複、欠測、台帳外の計測を拒否します。
- 画像ハッシュを照合し、全計測が成功して有限数値のスコアを持つことを確認します。
- モデル名、ソース版、重み版、前処理版の4項目が一致していることを確認します。
- 元画像グループ内で異なるラベルを混ぜません。実写と全体生成のグループが最低1個ずつ必要です。

加工条件オブジェクトも調整データ識別子の計算へ含めます。
実際のタイル数など画像ごとに変わる記録は許容します。同じ処理であることは前処理版で照合します。
部分生成編集と不明ラベルのグループは目標値の計算に使いません。
これらを除外したことと各ラベルのグループ数を設定に保存します。

## 候補と選択規則

比較演算は`score >= threshold`です。同点の画像を別々の判定に分けません。
候補は全ての異なるスコアと、最大スコアの直後に表現できる浮動小数点数です。
最後の値が無限大になる場合は候補へ追加しません。

実写グループは1枚でも陽性なら誤検知とします。全体生成グループは全派生条件が
陽性の場合だけ検出とします。したがって実写はグループ内最大スコア、全体生成は
グループ内最小スコアで判定します。分母は画像枚数ではなく元画像グループ数です。

誤検知率0.1%以下と全体生成検出率90%以上を同時に満たす候補に
`meets_targets: true`を付けます。境界付近の丸めを避けるため、達成判定は
`誤検知グループ数 × 1000 <= 実写グループ数`と
`検出グループ数 × 10 >= 全体生成グループ数 × 9`で行います。

達成候補の中で検出数が最大、次に誤検知数が最小、次に境界が最大の候補を選びます。
達成候補がない場合も、誤検知率の制約を満たす候補に同じ順序を適用します。
その制約すら満たせない場合は全候補から選びます。
入力の行順に依存せず、選択結果・全候補・分子・分母を保存します。

## 設定の利用と識別子

目標達成時も`status: candidate`、未達時は`status: unmet`です。
`usage`は常に`evaluation`です。調整データでの達成は最終評価での検証ではありません。
本番への昇格機能はありません。

公開関数は次の3個です。

- `calibrate_records(ledger, measurements, split="tuning")`は判定設定を返します。
- `validate_config(config, measurement=None, usage="evaluation")`は不整合を`ValueError`で拒否します。
  候補は評価用途だけで利用できます。未達設定は判定に適用しません。
  最終評価処理は未達設定を「未達・判定未適用」として報告してください。
  本番には`status: validated`かつ`usage: production`が必要です。
- `config_id_for(config)`は設定内容に対応する識別子を返します。

`calibration_id`は画像ID・ハッシュ・元画像グループ・ラベル・生スコア・加工条件と
モデル条件を決定的なJSONへ変換したSHA-256です。
`calibration_images`には画像ID・ハッシュ・元画像グループを保存します。

`config_id`は自分自身を除いた設定全体のSHA-256です。
JSON変換は`json.dumps(payload, sort_keys=True, separators=(",", ":"), allow_nan=False)`、
文字コードはUTF-8です。設定を意図して変更する場合は
`config["config_id"] = config_id_for(config)`で再計算します。
検証処理は内容と識別子の一致も検査します。これは変更の検知であり、発行者の電子署名ではありません。
調整識別子、画像識別情報、目標、必須来歴検査の形式も検査します。

```sh
uv run python -m unittest discover -s tests -p test_calibration.py -v
```

テストは固定した小さな計測記録を使います。写真、GPU、外部サービスは不要です。
