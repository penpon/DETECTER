# 調査依頼: SNS投稿画像(EXIF無し・再圧縮済み)のAI検出が壊滅する原因と、VLM/マルチモーダルOSSによるモダンな代替フロー (2026-09時点)

  ## 前提: 実運用の対象分布

  判定対象はSNS掲載画像。EXIF・メタデータは剥落し、JPEG再圧縮・リサイズ済み。実写・生成の双方が同じ加工を通る。

  壊滅的劣化が確認済み。JPEG再圧縮+縮小で生成側の高スコア帯が崩壊し、スクリーンショット混入の実写拡大が実写最大スコアを押し上げた。

  ## 検証してほしい仮説

  H1. 周波数・アーティファクト系検出器はSNS加工で構造的に死ぬ: JPEG再圧縮・縮小は高周波成分を潰し、diffusion/生成器の痕跡信号を消去する。既知の定量報告はある
  か。

  H2. 意味・コンテンツ系の判定はSNS耐性がある: 画素統計ではなく意味理解 (不自然なテキスト、物理破綻、人物の歪み、オブジェクトの不整合) で検出するVLM/マルチ
  モーダルLLMベースの手法は、再圧縮でも信号が残る。2024–2026の論文・ベンチマークで確認せよ。

  H3. VLM単体の判定精度が既存検出器を上回る: GPT-4V/Gemini級の商用VLMや、Qwen2.5-VL / InternVL / LLaVA等のOSS VLMに「これはAI生成か?」と聞くゼロショット・few-
  shot検出が、SNS加工下でUFD/CF/CuReを上回るか。

  H4. VLM向けの検出専用OSSが存在する: AI画像検出を目的にファインチューンされたOSS VLMまたはVLM検出フレームワーク (例: Lens, FakeBench系, Effort, CO-SPY, SAFE/
  FatFormer系, AIGCDetect系) がコード・重み公開されている。SNS/robustness評価の有無を確認。

  H5. ハイブリッドが必須: 意味系(VLM) + 低レベル系(従来検出器) + 来歴系(C2PA/SynthID) の多段構成で、SNS加工下でもFPR≤0.1% & TPR≥90%に届く設計があるか。

  H6. SNS耐性ベンチマーク: AI画像検出の「JPEG/リサイズ/メタデータ剥落」耐性を明示的に測ったベンチマーク (例: AIGCDetect-Bench, FakeBench, TIFA等) での順位と、
  コード公開有無。

  ## 調査論点

  1. 2025–2026のSNS耐性を持つ検出器: JPEG再圧縮・リサイズ耐性を評価した最新手法。論文/コード/重みの公開状況。
  2. VLM・マルチモーダルLLMによるAI画像検出: ゼロショット判定、ファインチューン済み検出VLM、推論型(reasoning)VLMでの判定精度。Jevのような「画像を入力として説
     明・判定する」OSS枠組みが検出器として使えるか。

  3. 意味系アーティファクト検出: テキスト崩壊・物理破綻・人物の歪み・鏡像/反射の不整合などを機械的に拾う手法 (2024–2026) とOSS実装。
  4. SNS耐性ベンチマークの実測: 各手法がJPEG品質75程度・縮小1024px程度の加工下でどこまで性能が保たれるかの定量値。
  5. 生成器識別 (attribution) の最新手法: GPT Image 2・Nano Banana級の生成器を識別するOSS/論文と、SNS加工下での有効性。
  6. 統計設計: FPR≤0.1%をSNS加工済みデータで片側95%証明するのに必要な群数と、現実的な到達目標。
